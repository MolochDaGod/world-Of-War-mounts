---
name: Army setup flow
description: Required order and persistent layout for the pre-battle commander choice.
---

Players choose a field commander before viewing or composing the army roster. After confirmation, the selected commander remains visible as a compact, editable card in the bottom-right of the army setup screen.

**Why:** The user wants commander identity to establish the army-building context rather than be an afterthought below the roster.

**How to apply:** Preserve the commander-first gate when evolving the setup flow. Keep a clearly labelled control that returns to commander selection without discarding the composed army.
